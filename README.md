# WardrobeAI

WardrobeAI is an Expo-powered React Native mobile app starter for a modern wardrobe management experience.

## Getting started

Install dependencies and start the Expo development server:

```bash
npm install
npm start
```

The default screen is **My Closet**, which includes a responsive wardrobe grid with six placeholder clothing cards and a floating add button.

Tap the **+** button to open the premium **Upload Item** modal, where a user can add a clothing photo, review AI auto-generated tags, edit category/color/brand/condition fields, and save the item to their wardrobe.

The **Market** tab now shows a premium secondhand grid. Tap any closet item to open its detail modal, then use **Sell on Market (8% Fee)** to simulate one-click selling with an instant listing confirmation.
